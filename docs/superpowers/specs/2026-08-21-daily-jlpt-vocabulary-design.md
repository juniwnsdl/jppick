# JLPT 오늘의 단어 기능 설계

- 작성일: 2026-08-21
- 대상: 가나 학습 웹앱 홈과 공통 헤더
- 데이터 출처: OpenJLPT N1~N5 vocabulary JSON

## 1. 목표

홈의 `바로 시작하기`와 `학습 현황` 사이에 매일 5개의 JLPT 단어를 표시한다. 단어는 앱에 포함된 정적 데이터만 사용하며 외부 API, 데이터베이스, 계정 기능은 추가하지 않는다.

각 단어는 다음 정보를 표시한다.

```text
あざ笑う                                      N1
あざわらう · 아자와라우
비웃다, 조롱하다
```

초기 난이도는 N1, N2, N3이며 사용자는 헤더 설정에서 다음 날부터 사용할 레벨을 선택할 수 있다.

## 2. 범위

### 포함

- OpenJLPT N1~N5 vocabulary 원본 파일만 프로젝트에 보관
- 8,334개 단어의 간결한 한국어 뜻과 학습용 한글 발음 생성
- 레벨별 실행용 경량 JSON 다섯 개 생성
- 로컬 날짜 기반의 결정적 5개 선택
- 선택 레벨 간 균형 배분과 단어 중복 방지
- 홈의 오늘의 단어 카드와 레벨 배지
- 헤더 설정 아이콘과 접근 가능한 난이도 모달
- 오늘 설정을 바꾸면 다음 로컬 날짜부터 적용
- 단위, 컴포넌트, 반응형 E2E 테스트

### 제외

- 단어 검색, 퀴즈, 암기 기록, 예문 표시
- 외부 API, Supabase, 서버 DB
- 관리자 계정과 원격 설정
- OpenJLPT 전체 저장소 복사

## 3. 데이터 구조

원본과 실행용 데이터를 분리한다.

```text
data/vendor/openjlpt/vocab/
├── n1.json
├── n2.json
├── n3.json
├── n4.json
└── n5.json

public/data/jlpt/
├── n1.json
├── n2.json
├── n3.json
├── n4.json
└── n5.json
```

원본 파일은 OpenJLPT에서 받은 상태를 유지한다. 실행용 파일은 현재 기능에 필요한 필드만 포함한다.

```ts
type JlptLevel = "N1" | "N2" | "N3" | "N4" | "N5";

interface VocabularyWord {
  word: string;
  reading: string;
  pronunciationKo: string;
  meaningKo: string;
  level: JlptLevel;
}
```

원본 `reading`이 비어 있고 `word`가 가나 표기라면 `word`를 실행용 `reading`으로 사용한다. 한국어 뜻은 개인 학습에 적합한 짧은 사전형 표현으로 만들며 대표 뜻이 여러 개면 쉼표로 구분한다. 한글 발음은 `reading`을 기준으로 일관된 학습용 표기를 사용한다.

실행용 데이터 생성 후 모든 항목의 필수 필드, 레벨, 원본 대비 개수와 중복 키를 검증하는 스크립트를 둔다. 출처와 사용한 OpenJLPT 커밋은 기존 `public/THIRD_PARTY_LICENSES.md`에 기록한다.

## 4. 데이터 로딩

레벨과 정적 파일 URL을 연결하는 로더를 단어 기능 내부에 둔다. 홈은 현재 활성 레벨 파일만 병렬로 읽고 N1~N5 전체를 하나의 클라이언트 번들로 포함하지 않는다. 같은 레벨 요청은 재사용할 수 있게 캐시한다.

초기 상태에서는 N1, N2, N3 파일만 요청한다. 정적 파일 하나가 실패하면 오늘의 단어 영역에만 오류와 재시도 버튼을 표시하고 홈의 나머지 기능은 유지한다.

## 5. 설정 모델

기존 로컬 설정을 다음 스키마 버전으로 마이그레이션한다. 기존 쓰기 도우미 설정은 보존한다.

```ts
interface DailyWordLevelSettings {
  activeLevels: JlptLevel[];
  pendingLevels: JlptLevel[] | null;
  effectiveDate: string | null;
}
```

- 기본 활성 레벨은 `N1`, `N2`, `N3`이다.
- 저장 시 선택값을 `pendingLevels`에 두고 `effectiveDate`를 다음 로컬 날짜로 지정한다.
- 같은 날 다시 저장하면 대기 값을 마지막 선택으로 덮어쓴다.
- 현재 날짜가 `effectiveDate` 이상이면 대기 값을 활성 값으로 승격한다.
- 모든 체크박스를 해제한 설정은 저장하지 않는다.
- localStorage를 사용할 수 없으면 현재 실행 중 메모리에서 기본값으로 동작한다.

로컬 날짜 키는 `Date#getFullYear`, `getMonth`, `getDate`로 `YYYY-MM-DD`를 만들며 UTC 기반 `toISOString()`으로 날짜를 결정하지 않는다.

## 6. 매일 5개 선택

선택 로직은 부수 효과가 없는 함수로 분리한다.

```ts
getDailyWords(wordsByLevel, localDateKey, activeLevels, 5)
```

날짜와 레벨을 문자열 해시의 입력으로 사용하고 seeded shuffle을 적용한다. 원본 배열은 변경하지 않는다.

선택 레벨의 순서도 날짜 시드로 섞은 뒤 5개 슬롯을 순환 배분한다. 예를 들어 N1, N2, N3가 활성화된 날은 `2, 2, 1`개로 배분하고, 어느 레벨이 2개를 받는지는 날짜에 따라 바뀐다. 레벨이 하나면 해당 레벨에서 중복 없이 5개를 뽑고, 다섯 레벨이면 각 레벨에서 하나씩 뽑는다.

같은 날짜, 같은 활성 레벨, 같은 데이터에는 앱 재실행이나 새로고침 후에도 같은 순서의 다섯 단어가 나온다. 설정을 바꾼 당일에는 기존 활성 레벨과 단어가 유지된다.

## 7. 화면 구성

### 헤더 설정

공통 헤더 오른쪽 끝에 톱니바퀴 아이콘 버튼을 추가한다. 버튼의 접근 가능한 이름은 `오늘의 단어 설정`이다.

버튼을 누르면 `오늘의 단어 난이도` 모달을 연다. 모달에는 N1~N5 체크박스, `취소`, `저장` 버튼과 `변경한 난이도는 내일부터 적용됩니다` 안내를 표시한다. 열릴 때 대기 설정이 있으면 대기 값을, 없으면 활성 값을 체크 상태로 사용한다.

선택이 없으면 저장 버튼을 비활성화하고 이유를 표시한다. 저장 후 `내일부터 N2, N4 단어가 표시됩니다`와 같은 상태 메시지를 제공한다. 모달은 열릴 때 포커스를 내부로 옮기고, Tab 포커스를 가두며, Escape·취소·바깥 영역으로 닫고 닫힌 뒤 설정 버튼으로 포커스를 돌려준다.

### 오늘의 단어

홈의 `바로 시작하기` 바로 아래, `학습 현황` 바로 위에 `오늘의 단어` 섹션을 추가한다. 제목 옆에 사용자의 로컬 날짜를 표시한다.

각 카드는 일본어 표기, `reading · pronunciationKo`, 한국어 뜻, 작은 JLPT 레벨 배지를 표시한다. 모바일에서는 한 열, 넓은 화면에서는 가독성을 유지하는 반응형 그리드를 사용한다. 로딩 중에는 레이아웃이 크게 이동하지 않는 자리 표시를 제공한다.

## 8. 구성 요소 경계

- `vocabulary-types`: 레벨과 실행용 단어 타입
- `vocabulary-loader`: 레벨별 정적 JSON 로드와 검증
- `daily-word-selector`: 날짜 시드, 균형 배분, 중복 없는 선택
- `daily-word-settings`: 활성·대기 설정 저장과 다음 날 승격
- `DailyWords`: 홈 데이터 로딩과 카드 렌더링
- `DailyWordSettingsButton`: 헤더 아이콘, 모달, 저장 상태 안내
- 데이터 생성·검증 스크립트: 원본과 파생 파일의 완전성 검사

번역 작업은 레벨별로 파일을 완전히 분리한다. 첫 병렬 작업은 N1, N2, N3, 두 번째 병렬 작업은 N4, N5를 담당한다. 각 작업자는 자기 레벨의 실행용 JSON만 작성하며 공통 코드나 다른 레벨 파일은 수정하지 않는다. 공통 검증과 UI 통합은 번역 파일이 준비된 뒤 수행한다.

## 9. 테스트와 인수 기준

- N1~N5 실행용 데이터 개수가 원본과 일치하고 필수 필드가 모두 채워져 있다.
- 빈 원본 reading은 word로 보완된다.
- 같은 입력의 `getDailyWords`는 항상 같은 다섯 항목과 순서를 반환한다.
- 결과에 동일한 레벨·단어·읽기 키가 중복되지 않는다.
- 선택 레벨별 배분 수 차이는 최대 1이다.
- 로컬 자정 전후 날짜 키가 UTC 날짜와 무관하게 올바르게 바뀐다.
- 설정 변경 당일에는 활성 레벨이 유지되고 다음 날짜부터 대기 레벨이 승격된다.
- 기본값은 N1, N2, N3이며 최소 한 단계 선택 규칙이 적용된다.
- 모달의 포커스, Escape, 취소, 저장과 상태 안내가 동작한다.
- 홈에서 오늘의 단어 다섯 개와 레벨 배지가 보인다.
- 데이터 오류가 홈의 기존 바로 시작하기와 학습 현황을 막지 않는다.
- 320×568 모바일과 데스크톱에서 헤더, 모달, 카드가 잘리거나 겹치지 않는다.
- 기존 전체 테스트, 린트, 타입 검사와 프로덕션 빌드가 통과한다.

## 10. 기존 작업 보호

현재 작업 트리에 존재하는 가나 차트와 E2E 관련 변경은 이번 기능의 소유가 아니다. 구현 중 해당 변경을 되돌리거나 덮어쓰지 않으며, 겹치는 파일인 `globals.css`와 E2E 테스트는 기존 변경을 보존한 상태에서 최소 범위로 편집한다.
